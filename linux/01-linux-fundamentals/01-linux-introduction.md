# What is an Operating System?

An Operating System (OS) is system software that acts as an interface between users, applications and computer hardware.

It manages computer resources and provides an environment to run applications.

### Examples of Operating Systems

1. Windows
2. Linux
3. macOS
4. UNIX
5. Android
6. iOS

### Responsibilities of an Operating System

- Process management
- Memory management
- File management
- Device management
- User management
- Security management
- Network management

### Example

When we open a browser on our computer:

1. The user opens the browser.
2. The Operating System allocates memory.
3. The Operating System creates a process.
4. The browser uses network resources.
5. The Operating System communicates with hardware.

The Operating System manages all these activities.

# What is Linux?

Linux is an open-source, Unix-like operating system built around the Linux kernel.

The Linux kernel was initially developed by Linus Torvalds in 1991.

Linux is widely used in:

- Cloud computing
- Web servers
- Application servers
- Database servers
- Containers
- Kubernetes
- Networking devices
- Embedded systems
- Supercomputers

### Why do companies use Linux?

Companies prefer Linux for many workloads because:

1. It is open source.
2. It is stable and reliable.
3. It supports multiple users.
4. It supports multitasking.
5. It provides strong security capabilities.
6. It supports automation and scripting.
7. It works efficiently on servers.
8. It integrates well with Cloud and DevOps tools.

### Real-Time Example

Consider an e-commerce application.

The application may contain:

- Frontend application
- Backend application
- Database
- Web server
- Monitoring tools

These components can run on separate Linux servers.

A DevOps Engineer manages these servers, installs required software, configures services, monitors logs and troubleshoots issues.

# What is a Linux Kernel?

The kernel is the core component of the Linux operating system.

It acts as an interface between hardware and software.

### Responsibilities of the Kernel

1. Process management
2. Memory management
3. Device management
4. File system management
5. Network management
6. Resource allocation

# What is a Linux Distribution?

A Linux distribution (distro) is a complete operating system built using the Linux kernel along with system utilities, libraries, package managers and applications.

Different companies and communities maintain different Linux distributions.

### Popular Linux Distributions

| Distribution | Maintained by / Associated with | Common Usage |
|---|---|---|
| Ubuntu | Canonical | Cloud and application servers |
| RHEL | Red Hat | Enterprise servers |
| Amazon Linux | AWS | AWS EC2 workloads |
| Debian | Debian Project | Servers and infrastructure |
| Fedora | Fedora Project | Development and innovation |
| SUSE Linux | SUSE | Enterprise environments |

# Linux vs Windows

| Feature | Linux | Windows |
|---|---|---|
| Source code | Open source (most distributions) | Proprietary |
| User interface | CLI and GUI | GUI and CLI |
| Security | Strong permissions and security controls | Strong security controls |
| Customization | Highly customizable | More restricted |
| Automation | Bash, Python and other tools | PowerShell and other tools |
| Server usage | Widely used | Widely used |
| File system | ext4, XFS and others | NTFS, ReFS and others |
| Package management | apt, dnf, yum | winget, Windows package tools |
| Administration | SSH, CLI and management tools | RDP, PowerShell and management tools |

### Which one is better?

Neither operating system is universally better.

It depends on the workload.

For example:

- Linux is widely used for cloud-native applications, containers and Kubernetes.
- Windows is widely used for Windows-specific enterprise applications, Active Directory environments and .NET workloads.
- Organizations often use both operating systems.

# Important Features of Linux

### 1. Open Source

Linux source code is available for inspection, modification and redistribution under its applicable licenses.

### 2. Multiuser

Multiple users can access the same Linux system with different permissions.

### 3. Multitasking

Linux can execute multiple processes simultaneously.

### 4. Security

Linux provides:

- User authentication
- File permissions
- Ownership
- Access control
- Firewall capabilities
- Security frameworks such as SELinux and AppArmor

### 5. Portability

Linux runs on different hardware architectures, including x86-64 and ARM.

### 6. Stability

Linux is widely used for long-running server workloads.

### 7. Automation

Linux supports automation using:

- Shell scripting
- Python
- Cron jobs
- Ansible
- Terraform
- CI/CD tools
