# Linux for Cloud & DevOps Engineers

## Course Overview

This module covers Linux administration and troubleshooting concepts required for Cloud Engineers, DevOps Engineers, SREs and Platform Engineers.

## Course Duration

6 Classes

## Course Objectives

By the end of this module, students will be able to:

- Understand Linux architecture and filesystem.
- Work with Linux commands.
- Manage users and groups.
- Configure file and directory permissions.
- Install and manage Linux packages.
- Manage processes and services.
- Troubleshoot Linux networking issues.
- Connect to remote Linux servers using SSH.
- Analyze Linux logs.
- Monitor CPU, memory and disk utilization.
- Deploy a web application on an AWS EC2 Linux server.

## Course Curriculum

| Class | Topics |
|---|---|
| 01 | Linux Fundamentals and File System |
| 02 | Users, Permissions and Text Processing |
| 03 | Package Management, Processes and Services |
| 04 | Linux Networking and SSH |
| 05 | Storage, Logs and Troubleshooting |
| 06 | Real-Time DevOps Project |

## Prerequisites

- Basic computer knowledge.
- Basic understanding of operating systems.
- AWS account for the final practical project (optional alternative: local Linux VM).

## Lab Environment

- Amazon Linux 2023
- Ubuntu Linux
- AWS EC2
- Git Bash / SSH Client

## Final Project

Deploy a sample web application on an AWS EC2 Linux instance using Nginx, configure systemd services, and troubleshoot application and server issues.

## Learning Approach

80% Hands-on Practical Exercises  
20% Theory and Concepts
